## Parcours

### Ingénieur statisticien — Ifremer

**18 mois d'expérience**

Mon expérience à l'Ifremer m'a permis de travailler sur des problématiques réelles d'analyse de données dans le domaine des pêches maritimes.

L'un des principaux objectifs de mon travail était d'améliorer l'estimation de différents indicateurs liés à l'activité de pêche à partir de plusieurs sources de données présentant des caractéristiques et des biais différents.

#### Données

J'ai notamment travaillé avec deux sources principales :

* **ObsDeb** : données issues d'un plan d'échantillonnage comprenant notamment des enquêtes téléphoniques et des enquêtes réalisées dans les ports ;
* **SACROIS** : données déclaratives renseignées par les pêcheurs, beaucoup plus nombreuses mais dont la représentativité statistique est différente.

Le travail nécessitait donc de **structurer, nettoyer, harmoniser et comparer des sources de données hétérogènes** avant de pouvoir les exploiter statistiquement.

#### Principales problématiques

* préparation et contrôle qualité des données ;
* détection et traitement de données incohérentes ou non crédibles ;
* harmonisation de plusieurs sources de données ;
* estimation d'indicateurs statistiques liés à l'activité de pêche ;
* comparaison de différentes méthodes d'estimation ;
* validation des méthodes par simulation ;
* analyse des biais et de la variabilité des estimateurs ;
* automatisation et reproductibilité des analyses.

#### Développement

Une partie importante du travail consistait à transformer les analyses statistiques en outils réutilisables.

J'ai notamment :

* développé des fonctions d'analyse en **R** ;
* participé à la création d'un **package R interne** ;
* développé des pipelines de traitement de données ;
* automatisé la production de rapports avec **Quarto** ;
* mis en place des analyses reproductibles pouvant être exécutées pour différentes régions et périodes ;
* utilisé **Git et GitLab** pour le versionnement du code.

#### Machine Learning

J'ai également utilisé des méthodes de **Machine Learning**, notamment des **Random Forests**, pour modéliser certains indicateurs statistiques.

Ces modèles ont notamment nécessité :

* la préparation des jeux d'apprentissage et de test ;
* l'entraînement des modèles ;
* l'optimisation des hyperparamètres ;
* la comparaison des performances ;
* l'évaluation des résultats.

Technologies principales :

`R` · `tidyverse` · `ggplot2` · `caret` · `ranger` · `Quarto` · `Git` · `GitLab`
